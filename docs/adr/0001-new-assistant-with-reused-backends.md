# 新工具复用既有后端能力，不迁移旧工具

2026-09-26 补充：本项目仓库更名为 `chrichuang218/claude-desktop-cn`，新版更新源随之迁移；下文旧仓库名为初版历史记录。内部产品与配置标识继续保留。

项目以最初的 B 版界面为起点构建独立的 Claude 中文助手（界面后续已调整；本文记录后端复用与不迁移边界），并沿用之前项目的后端能力。以当前仓库已有的 React、TypeScript、Tauri 2 / Rust 为基础，复用 Claude updater 的官方安装与注册能力、汉化项目的脚本适配，以及 Codex 助手的校验式自更新链路；只做整合所需的适配和明确缺陷修复，不照搬旧 UI 编排。

本工具不迁移旧助手配置、缓存或安装目录，也不自动删除旧工具。检测和使用本机已安装的官方 Claude 属于管理现有应用，不属于旧助手迁移。助手自更新固定指向 `chrichuang218/claude-windows-cn`，不能继续使用旧工具的发行包。首个公开版本继续沿用上述边界。
