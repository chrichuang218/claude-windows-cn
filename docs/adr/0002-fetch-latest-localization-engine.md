# 每次补丁操作获取最新汉化引擎

## 2026-09-24 修订：在线校验后复用同修订缓存

用户要求汉化和恢复时版本一致不用重复下载。此后“获取最新”指每次先在线验证汉化引擎自身的最新修订；远端确认未变，且本地原始缓存内容完整性校验通过时可以复用。引擎版本独立于 Claude 版本。远端变更或缓存损坏时下载，网络失败不得静默回退旧缓存。每次操作仍使用独立工作目录、执行适配和结构检查。下文原“重新获取最新内容”不再要求每次传输整个压缩包。

用户明确选择每次使用最新汉化引擎，因为汉化需要跟进 Claude 版本。沿用 `javaht/claude-desktop-zh-cn` 的在线来源，在应用汉化和恢复前重新获取最新内容，不固定到某个 commit，也不静默回退到旧缓存。

这会使运行结果受到上游变化影响。下载失败、脚本结构不兼容或目标校验失败时必须明确停止；记录本次引擎来源与下载文件摘要供日志追溯，不能为追求兼容吞掉错误或报告假成功。
